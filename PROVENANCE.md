# Asal source

Export ini berasal dari folder lokal AdminApp dan MovieApp. Tidak ditemukan metadata Git, URL upstream, LICENSE, NOTICE, COPYING, atau AUTHORS pada folder yang diaudit. Komentar tutorial dan nama package merupakan petunjuk, bukan bukti hak cipta atau izin distribusi.

Source Java, layout, ikon dan gambar asal dipertahankan kecuali perbaikan fungsional yang dijelaskan README. Tidak ada klaim bahwa aset berasal dari penulis perapihan. Tidak ada lisensi baru yang ditetapkan. Jika upstream atau ketentuan aset ditemukan kemudian, lengkapi atribusi dan lisensi yang sah sebelum memakai kode/aset di luar cakupan yang diizinkan.

Konfigurasi cloud pribadi, credential/signing key, path SDK, cache dan output build dikeluarkan dari export. Varian sumber lokal tetap dipertahankan terpisah.
